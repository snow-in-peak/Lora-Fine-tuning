# 乔峰智能问答系统

一个基于本地 Web 界面与远程模型服务的智能问答项目。

这个项目主要解决的是：用户在本地浏览器里输入问题，由本地后端接收请求，再通过 Socket 连接远程服务器，把问题发送给模型处理，最后把结果返回到网页端展示。整体流程清楚，部署方式也比较轻量，适合作为课程设计、项目展示或功能原型来使用。

---

## 项目简介

项目采用“前端页面 + 本地后端 + 远程模型服务”的方式搭建。前端负责交互展示，本地后端负责转发请求，远程服务器负责模型推理。这样做的好处是，本地运行压力较小，模型可以独立部署在服务器上，后续维护和扩展也更方便。

对于展示型项目来说，这套结构比较完整，能够体现一个智能问答系统从界面到后端通信，再到模型调用的完整链路。

---

## 项目能做什么

目前这个版本已经实现了这些基础功能：

- 在网页端输入问题并提交
- 本地 Flask 服务接收请求
- 通过 TCP Socket 连接远程模型服务
- 将模型返回结果展示到前端页面
- 支持 Ubuntu 环境下快速启动

虽然项目整体比较轻量，但核心流程是完整的，适合作为后续继续扩展的基础版本。

---

## 系统结构

项目整体调用流程如下：

```text
浏览器前端 -> 本地 Flask 后端 -> 远程模型服务器 -> 返回结果到前端
```

其中远程模型服务地址为：

```text
43.167.172.63:36000
```

也就是说，这个项目不是在本地直接跑模型，而是由本地后端主动去连接远程服务器上的模型服务，再把结果传回浏览器。这个思路比较适合本地展示、远程部署的应用场景。fileciteturn0file0

## 运行环境

建议在 Ubuntu 环境下运行，基础环境如下：

- Python 3.9 及以上
- pip
- 浏览器
- 可访问远程服务器的网络环境

如果远程服务器没有启动对应的 Socket 服务，本地页面虽然能打开，但无法拿到模型返回结果。fileciteturn0file0

## 启动方式

### 1. 进入项目目录

```bash
cd qiaofeng_local_app_ubuntu
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 给启动脚本授权

```bash

```

